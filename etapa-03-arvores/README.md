# Etapa 03 — Árvores e Gestão de Alarmes

## Escopo
- Estrutura hierárquica de ativos da planta.
- Árvores binárias de busca para consulta de tags.
- Mapeamento de dependência entre alarmes.
- Supressão de alarmes secundários e priorização na IHM.
- Árvore de decisão para protocolo de trip (shutdown).

## Entregáveis esperados
- Árvore de ativos e módulo de consulta `O(log n)`.
- Algoritmo de supressão de alarm flood.
- Interface de eventos priorizados.
- Código do algoritmo de parada segura.
